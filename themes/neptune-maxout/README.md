# Neptune Maxout KlipperScreen theme

This theme uses the HDR Performance Neptune Maxout charcoal, black, and red visual identity. It is designed for the BIGTREETECH Pad 7 at 1024 x 600 and also follows KlipperScreen's portrait layout when the Pad is rotated.

The installer copies the complete `material-dark` icon set from the installed KlipperScreen version before adding the Neptune Maxout badge. This keeps every standard KlipperScreen panel and future icon compatible with the version installed on the Pad.

Install from the repository root:

```text
./tools/install-neptune-maxout-theme.sh
```

Revert at any time from **Settings > Appearance > Colorized** or **Material Dark**, or run:

```text
./tools/install-neptune-maxout-theme.sh --restore-material-dark
```
