# Maxout FlowTech Orca Profiles 0.2.0 Beta

This is the first downloadable release of the HDR Maxout OrcaSlicer profile pack for the Neptune 3 Max with the project-supported SKR 3 EZ, upgraded X/Y motors, direct drive, Klipper, and Micro Swiss FlowTech configuration.

## Download and install

1. Download `Maxout-FlowTech-Orca-Profiles-0.2.0-beta.zip` from the release assets.
2. Extract the ZIP completely.
3. Close OrcaSlicer.
4. Double-click `INSTALL-ORCA-PROFILES.cmd`.
5. Restart OrcaSlicer and select the Maxout FlowTech printer preset matching the installed nozzle.

See the [complete beginner installation tutorial](../ORCASLICER-FLOWTECH-EASY-INSTALL.md) for screenshots-independent manual instructions and safety notes.

## Included

- 4 printer presets: 0.4, 0.6, 0.8, and 1.0 mm
- 20 process presets: 0.10, 0.15, 0.20, 0.30, and 0.32 mm layer heights for each nozzle
- 47 filament starting profiles covering popular brands, common materials, and CF/GF composites
- automatic backup of same-named profiles during installation
- manual installation fallback

## Beta and safety notice

The pack passed structural validation and hardware guardrails. The 0.4 mm / 0.20 mm process is a local baseline; the other process and filament combinations remain candidate starting points until physically validated.

CF/GF composites require a hardened abrasion-resistant FlowTech-compatible nozzle of at least 0.6 mm. Engineering materials require the enclosure, ventilation, and drying specified by their manufacturer. Calibrate every material, color, nozzle, and printer before production use.
